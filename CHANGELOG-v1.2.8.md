# panel-script-v1 1.2.8

Исправлен живой сценарий Remnawave 3.3.0, в котором bridge-user сначала
подтверждался в `PSV1-CASCADE`, но после добавления relay inbound финальная
проверка видела его без squad.

- увеличено ожидание согласованного состояния пользователя;
- bridge-user повторно подтверждается после формирования окончательного squad;
- post-check может один раз идемпотентно восстановить членство;
- восстановленное состояние обязательно перечитывается;
- при отказе сохраняется redacted-снимок фактического user JSON;
- все 16 сценарных тестов проходят.
