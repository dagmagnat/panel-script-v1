## 🎯 Что было сделано

### Суть изменений

Для каждого из 6 методов CDN (VK Cloud, Yandex, Beeline, Timeweb, Selectel, TurboFlare) добавлена возможность выбрать тип origin:

```
┌─ Метод CDN (1-6)
├─ Выбор типа origin:
│  ├─ Заглушка (Placeholder) на localhost:порт
│  └─ SFTP Go на localhost:8080
└─ Автоматическое конфигурирование
```

### Добавленные функции

| Функция | Строки | Назначение |
|---------|--------|-----------|
| `method_title()` | 221-231 | Преобразование кода метода в название |
| `rm_manager_choose_origin_type()` | 793-810 | Интерактивное меню выбора |
| `rm_manager_get_origin_port()` | 812-842 | Определение порта |
| `rm_manager_get_origin_scheme()` | 844-852 | Определение схемы (http/https) |
| `rm_manager_collect_domains()` | 854-909 | **Обновлена** для выбора типа |
| `rm_manager_provider_steps()` | 1260+ | **Обновлена** с информацией о типе |

## 📊 Примеры конфигураций

### Пример 1: Timeweb + Placeholder
```

Origin: placeholder (127.0.0.1:80)
CDN: cdn.example.com
```

### Пример 2: VK Cloud + SFTP Go
```
Method: vk
Origin: sftpgo (127.0.0.1:8080)
Origin Domain: origin.example.net
CDN: cdn.example.net
```

После выбора доступны:

```bash
ORIGIN_TYPE     # "placeholder" или "sftpgo"
ORIGIN_PORT     # порт (80, 443, или 8080)
ORIGIN_SCHEME   # "http"
ORIGIN_DOMAIN   # домен origin (если указан)
CDN_DOMAIN      # CDN домен (если указан)
```
