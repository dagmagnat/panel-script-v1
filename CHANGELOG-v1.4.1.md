# panel-script-v1 1.4.1

Исправлено отсутствующее переключение origin nginx с базового XHTTP inbound на
каскадный `127.0.0.1:7443`.

Новая команда на relay:

```bash
/root/panel-script-v1.sh --cascade-relay-nginx
```

Она изменяет только однозначно найденный `upstream xray_xhttp`. До изменения
проверяется ответ `400` от локального cascade inbound; после — синтаксис nginx,
graceful reload и ответ `400` через локальный HTTPS-vhost. При любой ошибке
восстанавливается сохранённая копия. Уже исправленная вручную конфигурация
только проверяется и не переписывается.
