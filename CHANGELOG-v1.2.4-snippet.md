## 1.2.4
- Исправлен `--cascade`: если Remnawave API не найден автоматически, мастер больше не завершается ложной ошибкой — предлагает вручную указать URL панели. Сохраняется возможность запуска через `RM_API_BASE=https://...`.
- Исправлена совместимость bridge-user с Remnawave 3.3.0: успешный `POST /api/users` может возвращать `id`/`shortUuid`/`vlessUuid` без поля `uuid`. Теперь успех определяется по `vlessUuid` и фактическому членству в `PSV1-CASCADE`.
- Повторный запуск каскада больше не пытается создать дубликат bridge-user только из-за отсутствия `.uuid`; существующий пользователь переиспользуется по `vlessUuid`.
- Диагностический `last-api-error-cascade-user.json` теперь редактирует credential-поля (`password`, `token`, `secret`, `subscriptionUrl`, `vlessUuid`) перед записью.
- Добавлена защита TurboFlare от опасного NS-конфликта: мастер останавливается до API-изменений, если клиентский TurboFlare-домен является родительской DNS-зоной для панели и/или origin (например `aer01.ru` при `pnl.aer01.ru`/`video.aer01.ru`).
- В итог `--cascade` добавлено явное предупреждение: обычных пользователей нужно добавить в `PSV1-CASCADE`, иначе Cascade Host не появится в их подписке.
