# panel-script-v1 1.3.1

Исправлен ложный откат сертификата после graceful reload nginx. Версия 1.3.0
проверяла TLS немедленно, поэтому первое соединение иногда попадало в старый
worker и всё ещё видело self-signed сертификат.

Теперь скрипт до 20 секунд сравнивает SHA-256 fingerprint сертификата,
фактически отдаваемого nginx, с выпущенным сертификатом. Только после их
совпадения выполняется обычная проверка HTTPS без `-k`.

Сертификат, уже выпущенный версией 1.3.0, будет переиспользован:

```bash
/root/panel-script-v1.sh --panel-cert pnl.amoredd.ru
```
