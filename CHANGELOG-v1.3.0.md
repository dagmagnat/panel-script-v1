# panel-script-v1 1.3.0

Добавлена безопасная команда для выпуска действующего сертификата уже
работающей Remnawave-панели:

```bash
/root/panel-script-v1.sh --panel-cert pnl.amoredd.ru
```

Используется Certbot HTTP-01 в режиме `webroot`. Команда не запускает
standalone-server, не останавливает nginx, не освобождает порты `80/443` и не
перезапускает Docker, панель или ноды.

Перед выпуском проверяются DNS и реальная отдача challenge. Перед переключением
создаётся резервная копия активного vhost; меняются только пути сертификата.
После `nginx -t` выполняется graceful reload и TLS-проверка без `-k`. При ошибке
конфиг автоматически откатывается.
