panel-script-v1 v1.1.1 — БЫСТРЫЙ СТАРТ
======================================

ПУБЛИЧНЫЙ GITHUB:
https://github.com/dagmagnat/panel-script-v1

Команда на новом VPS:

curl -fsSL https://raw.githubusercontent.com/dagmagnat/panel-script-v1/main/install.sh -o /root/panel-script-v1.sh && chmod 700 /root/panel-script-v1.sh && /root/panel-script-v1.sh

ЕСЛИ ПАНЕЛЬ REMNAWAVE УЖЕ СТОИТ:
/root/panel-script-v1.sh --manage-remna

ЕСЛИ НОД ЕЩЁ НЕТ:
1) В панели: Nodes -> Create node
2) Address = IP европейского VPS
3) Выбери Node Port в панели (например 2222 или 2233) и запомни его
4) Скопировать SECRET_KEY
5) На европейском VPS запустить install.sh
6) Remnawave -> Только нода -> выбрать CDN
7) Ввести IP панели + SECRET_KEY
8) Вернуться на сервер панели
9) /root/panel-script-v1.sh --manage-remna
10) Выбрать эту ноду + тот же CDN

Можно иметь одновременно:
NODE-1 -> TurboFlare
NODE-2 -> Selectel
NODE-3 -> VK
и управлять ими из одной панели.

Рекомендуется: 1 VPS-нода = 1 CDN-метод.

TurboFlare:
Сайты -> домен -> Редактирование -> Адрес = IP НОДЫ:443
HTTPS к источнику = ВКЛ
Устаревший кэш = ВЫКЛ

Обновить скрипт:
/root/panel-script-v1.sh --update

Версия:
/root/panel-script-v1.sh --version


Если --manage-remna не видит localhost:3000:
- v1.1.2 сам попробует Docker и домен панели;
- затем можно ввести https://домен-панели;
- при недоступном API он всё равно создаст ручные файлы и NEXT-STEPS.txt.
