panel-script-v1 v1.2.8 — БЫСТРЫЙ СТАРТ
======================================

Новый VPS:

  chmod 700 install.sh
  ./install.sh

Существующая Remnawave:

  ./install.sh --manage-remna

Каскад Remnawave (запускать на сервере центральной панели):

  ./install.sh --cascade

Нужны минимум две подключённые ноды:
  - RU relay принимает CDN-трафик;
  - foreign exit слушает BRIDGE_IN TCP :8888.

Для TurboFlare на одном VPS с панелью поддерживается origin IP:443: мастер
сначала проверит точечный nginx bridge на 127.0.0.1:7443, затем изменит API.

Успешный автоматический каскад получает статус api-verified. Статус
failed-postcheck означает, что одно из обязательных условий не подтвердилось и
каскад нельзя считать готовым.

Проверки исходников:

  bash -n install.sh
  bash -n cascade-nginx-fix.sh
  bash tests/cascade-tests.sh

Версия:

  ./install.sh --version

Обновление из GitHub:

  ./install.sh --update
